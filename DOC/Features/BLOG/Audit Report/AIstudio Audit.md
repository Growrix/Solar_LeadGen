
Numbered Audit Findings & Prompts for Google AI Studio Implementation:

1. Cropping and Image Editing
Prompt: Add in-browser image editing tools to the MediaDetailsModal, allowing users to crop, rotate, and resize images for different aspect ratios (e.g., square, 16:9).

2. File Organization (Folders/Tags)
Prompt: Implement a robust folder tree or tag-based organization system in the AdminMediaLibrary, enabling users to browse, create, and manage folders and tags for media files.

3. Media Replacement
Prompt: Add a feature to replace an existing media file with a new version while retaining its ID and metadata, preventing broken links in posts.

4. Bulk Metadata Editing
Prompt: Enable bulk editing of media metadata, such as alt text and tags, for multiple selected items in the AdminMediaLibrary.

5. Usage Tracking
Prompt: Display a list of blog posts or pages that reference each media file in the MediaDetailsModal to prevent accidental deletion of assets in use.

6. Drag-and-Drop Organization
Prompt: Allow users to drag and drop media files into folders or categories within the media library view for easier organization.

7. Advanced File Types Support
Prompt: Enhance support for videos and documents by adding playable previews for videos and first-page previews for PDFs in the media library.

8. Image Optimization/Compression
Prompt: Implement automatic image compression and optimization upon upload, such as converting large PNGs to WebP, to improve blog performance.

9. Download Original
Prompt: Add a direct "Download" button for the original media file in the MediaDetailsModal for easy asset retrieval.

10. File Renaming
Prompt: Allow admins to rename media files after upload, updating either the display name or the URL slug as needed.

11. Filtering by Date Range
Prompt: Add a filter to the media library that allows users to search for media files by upload date range.

12. Grid Size Toggle
Prompt: Provide a slider or control to adjust the thumbnail size in the media library grid view, helping users scan large libraries more efficiently.

######################
13. Kanban Board View for Content Workflow
Prompt: Add a Kanban board view to the AdminPostList, allowing admins to visualize posts grouped by key lifecycle stages (Draft, Needs Review, Scheduled, Published). Enable drag-and-drop between columns for workflow management (UI-only).

14. Stats Ribbon in List View
Prompt: Add a stats ribbon at the top of the AdminPostList to show real-time counts for Total, Published, and In Review posts, providing immediate context for admins.

15. List/Board View Switcher
Prompt: Implement a toggle control in the AdminPostList to switch between traditional table (list) view and the new Kanban board view, supporting different admin preferences.

16. Enhanced Metadata Indicators
Prompt: Add visual indicators in both list and board views for missing or incomplete metadata (e.g., missing cover image, missing alt text), helping admins quickly identify content that needs attention.

17. Summary Bar for Content Overview
Prompt: Add a summary bar at the top of the AdminPostList displaying active post counts and key stats to provide immediate operational context.

18. Folder/Tag Organization for Content
Prompt: Implement a folder tree or tag-based organization system for posts (not just media), enabling admins to group, browse, and manage content more efficiently.

19. Bulk Content Actions
Prompt: Enable bulk actions (e.g., bulk publish, bulk archive, bulk assign tags) for selected posts in both list and board views, streamlining admin workflows.

20. Customizable Column/Field Visibility
Prompt: Allow admins to customize which columns or fields are visible in the AdminPostList and Kanban board, supporting different editorial needs and reducing clutter.

21. Inline Editing in List/Board Views
Prompt: Support inline editing for key fields (e.g., title, status, tags) directly in the list or board view, reducing the need to open the full editor for minor changes.

22. Management Dashboard Overview
Prompt: Add a management dashboard surface that aggregates stats, recent activity, and workflow bottlenecks for both content and media, giving admins a high-level operational overview.
