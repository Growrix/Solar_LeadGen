# Lead Admin Controls

## Overview
Specifies all admin actions and controls over the lead pipeline, including approval, assignment, pricing, and audit trail.

## User Stories
- As an Admin, I want to approve, assign, price, and archive leads.
- As an Admin, I want to monitor all actions and maintain a full audit trail.

## Requirements
- Manual and auto-approval of leads
- Assign to specific installers or groups
- Set/override prices
- Archive/close leads
- Full audit trail of all actions
- Notification triggers for all key actions

## Acceptance Criteria
- [ ] Admin can perform all actions via dashboard
- [ ] All actions are logged and auditable
- [ ] Only admin can archive/close leads

## Dependencies
- Lead Journey
- Lead Verification
- Lead Purchase
- Lead Chat

## Out of Scope
- User management outside of leads
