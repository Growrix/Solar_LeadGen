# Initial Plan Finalization Instruction

## Purpose
Guide the AI to convert raw research/brainstorming output into a finalized, development-ready initial plan for any feature or product.

---

## Workflow Steps

### 1. Organize Ideas into User Stories
- Group all ideas by user type/role (e.g., public user, admin, automation).
- For each, write user stories in the format:
  - "As a [role], I can [action], so that [value]."

### 2. Add Acceptance Criteria
- For each user story, add bullet-point acceptance criteria:
  - What must be true for the story to be considered complete?
  - What edge cases or constraints must be handled?

### 3. Clarify and Refine
- Remove duplicates and merge similar stories.
- Clarify any ambiguous or vague items.
- Ensure every story is actionable and testable.

### 4. Add Glossary/Definitions
- Define any domain-specific or ambiguous terms used in the stories.

### 5. Prioritize or Phase (Optional)
- Optionally, group stories by priority (must-have, nice-to-have) or by phase (MVP, Phase 2, etc.).

### 6. Output Format
- The finalized initial plan should be structured as:
  - User stories grouped by user type/role
  - Acceptance criteria for each story
  - Glossary/definitions section
  - (Optional) Prioritization/phasing

### 7. Review & Finalization
- Check that all user needs, features, and flows are covered.
- Ensure the plan is clear, unambiguous, and ready for frontend planning.

---

## Instructions for AI
- Follow these steps exactly, in order.
- Do not add, remove, or modify features unless explicitly instructed.
- Output the finalized initial plan in a clear, structured markdown format.
