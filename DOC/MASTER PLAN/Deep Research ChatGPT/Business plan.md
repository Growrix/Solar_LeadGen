# 9 — SaaS Technical Architecture (high-level, production-ready)

**Principles:** scalable, secure, auditable (register versioning), multi-tenant for installers, observability.

## Stack (recommended)

* Frontend: **React 18 + TypeScript** (Next.js 14 App Router for SSR + SEO), Tailwind CSS, Headless UI / shadcn components.
* Backend: **Node.js / TypeScript** (NestJS or Next.js API routes) or serverless (Vercel/Cloud Run).
* DB: **Postgres** (hosted – Supabase or AWS RDS), with JSONB for flexible register entries.
* Cache: **Redis** for sessions, rate limiting, and hot data.
* Storage: **S3 / Supabase Storage** for PDFs, receipts.
* Auth: **Auth.js** / Supabase Auth / OIDC (support Google/Apple sign-in for installers).
* Payments/Billing: **Stripe** (subscriptions, credits, on-demand payments).
* Messaging: **Twilio** (SMS) + SendGrid for email & transactional notifications.
* Task queue: **BullMQ / Sidekiq equivalent** for imports, CSV parsing, batch REC packet generation.
* Search: **Elasticsearch / Meilisearch** for model register search & installer discovery.
* Observability: **Sentry** + **Prometheus / Grafana** for metrics.
* CI/CD: GitHub Actions → auto-deploy to Vercel or AWS.

## Key components (services)

1. **Calculator Engine** (stateless microservice)

   * Functions: battery STC, PV STC, water heater STC, combined package.
   * Inputs validated via Zod; results cached with registerVersion tag.

2. **Register Importer**

   * Pulls CER registers & postcode zone files on schedule; stores versioned data; runs integrity checks; admin panel to approve imports.

3. **Lead Marketplace**

   * Lead intake API, lead enrichment (phone validation), routing & auction engine, credits accounting.

4. **Installer SaaS**

   * Multi-tenant schema: installer accounts, seats, subscription plan, credits balance, billing integration.
   * Features: CRM, Quote Builder, Calendar, REC automation.

5. **REC/Registry Assist**

   * Template generator producing CSV/JSON bundles for REC Registry, audit logs, attachment manager for photos + serial numbers.

6. **Admin Portal**

   * Manage tariffs, STC rates, leads, disputes, refunds, register versions, financial reconciliation.

## Data model (high-level)

* `users` (homeowner, installer)
* `installers` (profile, accreditation: CEC id, ABN, insurance)
* `leads` (lead_type, status, geography, calc_snapshot, assigned_to, paid)
* `calculations` (calculation_type, inputs, outputs, registerVersion)
* `register_models` (modelId, zoneSTCs, eligibleFrom, eligibleTo, rawPayload)
* `credits_transactions` (installerId, amount, type)
* `subscriptions` (stripeCustomerId, plan, status)
* `audit_logs` (calculationId, admin_user, action, timestamp)

## Security & compliance

* PCI DSS via Stripe for payment processing.
* PII: store minimal homeowner data; double opt-in; encryption at rest & transit (TLS).
* Privacy: comply with Australian Privacy Principles (APPs).
* Logging policy & data retention configurable per region.
