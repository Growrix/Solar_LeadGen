- **Why**: Constitution Article VI (Zero trust, Auth ≠ Authorization), Blueprint P5
- **Test**: Login with wrong-role credentials must fail with clear error

### PHASE 2: Notification Service Consolidation (CRITICAL)

- **Why**: P1 Single Source of Truth, Separation of Concerns

### PHASE 3: Email Link Source Unification (HIGH)

- **What**: Create `src/lib/config/app-url.ts` helper; use single source
- **Why**: Separation of Concerns, Security/Trust
- **Test**: All emails use same base URL

### PHASE 4: Email Delivery Audit Logging (HIGH)
- **Files**: Prisma schema, `src/lib/sendgrid.ts`, `src/lib/services/audit-logger.ts`
- **What**: Add `EmailDelivery` table; log provider ID, status, recipient role
- **Why**: Constitution Article VII (Auditability)

### PHASE 5: Deliverability Documentation (MEDIUM)

### PHASE 6: Event Orchestration Foundation (MEDIUM - foundational)
